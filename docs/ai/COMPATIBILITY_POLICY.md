# 兼容性与失败处理

本规则补充[根规则](../../AGENTS.md)。只为真实调用方、明确外部约定、持久化科研资产的迁移或用户明确要求提供兼容，不为可能的未来需求保留双路径。

## 可以保留的兼容

- 历史模型/配置仍需要读取时，明确版本并使用可追溯适配；保留原文件，迁移产生新文件。
- 旧入口仍有真实调用时，保留窄范围适配并测试；新入口验证后再按授权归档。
- 格式转换须记录单位、原子顺序和参数语义；能读文件不等于得到同一物理模型。

兼容路径须说明保护的约定、测试和退出条件。保留历史输入及报告不意味着永远维护旧执行代码，也不自动授予删除历史证据的权限。

## 禁止用兼容隐藏错误

- 不重新加入 PowerShell、WSL 或 Windows 专属运行路径。
- 不在力场/水模型/电荷/交叉项缺失时自动换另一套模型。
- 不以宽泛异常捕获、必需依赖的可选导入、隐式生成配置或补零掩盖错误。
- 不因旧格式缺字段就假造冻结哈希、验收状态、单位或独立重复数。
- 不因路径不可用而静默改写到源码、输入目录或未获准的其他存储位置。

## 迁移证据

对涉及科研数值的转换，比较必要的结构、原子映射、能量/力或观察量；具体标准由所属模型和协议给出，不设万能误差阈值。仅路径或文档迁移验证身份与引用，不要求无关的长计算。

错误消息应说明失败项、证据位置及下一步所需信息；不能把失败包装成带默认值的成功结果。
