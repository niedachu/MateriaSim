# 模型、场景、文献与验证的专属字段

这些是文档写作清单，不是可以直接加入实验 JSON 的字段。复用[公共元数据模板](knowledge.md)，按责任补正文，不建立空模型卡。

| 类型 | 必需内容 |
|---|---|
| 模型 | 身份、端基／质子化／表面状态、分辨率、版本与资产；拓扑参数来源、方法和阅读深度；相容条件、具体验证性质和失效边界 |
| 场景 | 问题、组成口径、几何与周期方向；构建路线和分支；协议理由；观察量、平衡／采样证据；现有能力与缺口 |
| 验证设计 | 要验证的主张、适用范围、参考基准；可证伪条件；指标与单位、阈值及依据、重复和统计方法、预算／授权与输出位置 |
| 文献笔记 | DOI／版本／章节；主文／SI／代码／数据阅读范围；原文结论、本地推断与假设分开；争议和未验证可迁移性 |
| 实际证据摘要 | 模型和输入／代码身份、环境、Run／阶段、分析请求与窗口、重复、指标、结果和失败；不可变原始证据位置与可访问性 |

物理参数只引用资产，不在说明里建立第二套可执行主版本。不可把“待验证”文本变成 purpose_policy 的 accepted 证据。

## C0 的使用方式

以下五份表可以复制到已批准的研究设计文档。填写“未选／未知／不适用及理由”优于猜值，但关键项未知时不能进入正式计算。填写人、日期、版本和研究问题应放在共同头部。表格是人工审查清单，不是平台 JSON 字段，也不是模型批准文件。

### 1. 模型审查表

| 字段 | 本研究填写 | 填写要求／拒绝条件 |
|---|---|---|
| 化学身份与状态 | 待研究选定 | 化学图、序列／端基、立构、质子化／表面状态；不能只填材料名 |
| 分辨率与约束假设 | 待研究选定 | AA/CG、固定部分、弹性网络等；说明影响的自由度 |
| 结构来源 | 待来源复核 | DOI／数据库标识、版本、实验／预测／构建来源及修改记录 |
| 参数来源与方法 | 待来源复核 | 力场版本、电荷方法、主文／SI／参数文件读取范围 |
| 资产与映射 | 尚未建立资产 | 文件哈希、原子映射、依赖闭包、单位、许可／再分发限制 |
| 覆盖与缺口 | 待逐项核查 | 未知类型、跨残基项、修饰或表面参数；缺失不得默认补齐 |
| 适用范围和失效 | 未评估 | 温压、相态、组成、目标性质及依据；文献报告与本地结果分开 |

参照[力场兼容](../models/force_field_compatibility.md)及对应材料页。

### 2. 相互作用审查表

对每种自作用、每对交叉作用填写一行；多体模型另附整体作用域，不把表当作其完整数学表达。

| 组分／作用域 | 模型版本与函数 | 参数或组合规则来源 | 单位、排除、1–4、截断／长程约定 | 验证条件与缺口 |
|---|---|---|---|---|
| 由实际模型清单生成 | 未选 | 未核查 | 未核查 | 未评估 |

共同附项：全局 defaults、总电荷、水／离子匹配、虚拟位点／约束兼容性、显式交叉项优先级、导出器能否保真。两套拓扑可拼接只回答格式问题；“使用组合规则”仍需说明其科学依据。

### 3. 场景与协议设计表

| 字段 | 本研究填写 | 说明 |
|---|---|---|
| 研究主张与目标量 | 待研究确定 | 描述结构、比较条件，还是估计动力学／热力学量 |
| 配方意图及解析账本 | 待配方确定 | 计量基准、整数数量、电荷、体积口径、取整偏差 |
| 几何／边界／参考态 | 待场景确定 | 周期方向、表面数量、可达体积、固定／可动对象 |
| 初态与重复 | 待设计 | 构建与速度种子分开；是否不同构象起点 |
| 准备与阶段交接 | 待设计 | 每阶段目的、状态继承、约束与温压选择理由 |
| 生产与停止规则 | 未授权运行 | 目标量、窗口、失败／追加条件，不以固定时长保证平衡 |
| 必需输出 | 待检查清单确定 | 能量、位置、速度等按方法需求，不能事后补造 |
| 工具、平台与预算 | 未授权运行 | 版本、CPU/GPU、时长、存储、费用及原始证据根位置 |

参照[聚合物场景](../scenarios/polymer_solutions_melts_networks.md)、[界面场景](../scenarios/interfaces_and_confined_systems.md)和[数值检查](../verification/numerical_protocol_checks.md)。不适用的阶段写理由，不机械补齐通用流水线。

### 4. 基准与统计设计表

| 字段 | 本研究填写 | 说明 |
|---|---|---|
| 要检验的主张 | 待确定 | 能被什么结果反驳；明确四类证据中的哪一层 |
| 参考数据 | 尚未选定 | DOI／版本、可访问性、测量／计算条件、误差和许可 |
| 拟合与独立验证 | 未评估 | 同一数据曾用于拟合时不能宣称独立验证 |
| 指标／估计器 | 待确定 | 选择、单位、归一化、PBC、窗口与样本总体 |
| 判据及依据 | 未预设 | 数值容差、科学效应大小、参考和统计误差分开 |
| 重复与相关性 | 待设计 | 初态来源、独立重复数、块长／相关估计、置信水平 |
| 敏感性对照 | 待设计 | 窗口、尺寸、步长或组成等，仅改变有目的的因素 |
| 失败／不足的处理 | 保留并报告 | 不删除不利重复；追加预算和改变模型需重新说明 |

参照[证据层次](../verification/evidence_levels.md)和[采样统计](../verification/sampling_uncertainty.md)。没有合理阈值时先做描述性比较，不在看过结果后改阈值制造通过。

### 5. 证据与复审表

| 字段 | 本研究填写 | 说明 |
|---|---|---|
| 代码／工具／输入身份 | 无实际运行 | 版本、哈希、环境和依赖；引用冻结事实，不用当前工作树代替 |
| Run 与分析定位 | 无实际运行 | 原始产物、日志、窗口、分析输入和命令、访问限制 |
| 工程／数值／采样／模型结果 | 均未运行 | 各项单独填通过／失败／未运行／不适用及理由 |
| 估计与不确定性 | 无结果 | 单位、方法、区间、重复、失败和缺失数据 |
| 支持的有限主张 | 尚无 | 明确材料、条件、性质和不能外推的范围 |
| 复审触发项 | 待研究确定 | 模型、场景、引擎、分析定义等变化的影响 |
| 审查人／日期／意见 | 尚未审查 | 明确人工责任；文档作者身份不等于独立审查 |

不能把以上空白清单或下面教学示例转成用途策略的 accepted 资产。

## 非执行教学示例：聚合物＋颗粒＋小分子＋水盐

此例展示如何填写决策，不选择具体材料或数值，不生成 catalog、研究包或 Run。

| 清单 | 可以现在写下的设计 | 进入实际研究前的阻塞项 |
|---|---|---|
| 模型 | 分别建立链、颗粒表面、小分子、水／离子的身份审查 | 尚无化学种类、端基、表面状态及兼容参数 |
| 相互作用 | 检查每个自作用及全部交叉作用；优先识别表面–水、表面–溶质和聚合物–溶剂风险 | 不能只核查这三对就忽略其他交叉作用 |
| 场景 | 若研究平衡吸附，先定义体相区、表面面积与颗粒周期镜像条件 | 尚无盒子、配方和慢过程时间尺度，不设通用 ns |
| 基准 | 比较含／不含聚合物的体系，明确匹配的是总溶质量还是体相化学条件 | 两者不是同一对照；需研究者按问题选择，并选可靠参考 |
| 分析 | 接触作为描述量；需要吸附结论则另用有定义的表面过量或适当方法 | 当前只有接触分析；未实现界面量，也没有真实结果 |
| 证据 | 四层状态均为未运行；缺口转交 C1/C2 | 不生成 accepted，不声称已经模拟复杂体系 |

这份示例可以帮助检查设计是否完整，不能替代具体体系的科学审查。
