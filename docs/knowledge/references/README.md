# 来源登记与阅读范围

[sources.json](sources.json) 是唯一来源登记。正文就近链接原文，头部 `source_refs` 引用稳定 ID；不另外维护一份可独立修改的文献表。

记录作者／维护者、版本、访问时间、章节或公式、实际阅读深度与未读材料。读取摘要不能填写“全文核验”；未取得 SI 或数据必须说明。本文库没有下载新数据、运行论文代码或保存全文副本。

本批 GROMACS 官方 `current` 页面显示 2026.3；直接版本号路径未成功访问，所以记录可变链接及所见版本，不伪造永久快照。它不是对本机安装版行为的保证。PyMBAR 与 MDAnalysis 文档分别固定 4.0.0 与 2.7.0。

Grossfield 文献记录存在网页发表时间 2018 与卷期/PDF 年份 2019 的差异，按 DOI 和 Article v1.0 定位并保留两者。已核读范围、未读代码和 SI 情况见登记，不写成完整论文复现。

每次扩展知识先找官方文档、原始论文／维护者资料；冲突记录定位、版本和双方陈述，再限定结论。来源网页也可能有错误，不能跳过量纲与实现核对。
