# 片段 RESP 改进与实施方案

## 1. 目的

本方案用于替代已经被拒绝的全分子 RESP 电荷拟合，同时保持项目的基本路线不变：

- 溶质：一个完整的目标两性离子分子；
- SMILES：`O=S(CCC[N+]1=CN(CCOCCOC)C=C1)([O-])=O`；
- 力场：GAFF2 键合与 Lennard-Jones 参数；
- 电荷：HF/6-31G* 静电势基础上的两阶段 RESP；
- 溶剂：AMBER TIP3P 纯水；
- 条件：298.15 K、1 bar；
- 最终问题：完整分子第一水化层中的去重水分子数。

片段 RESP 只改变原子电荷的获得方式。最终拓扑仍然是一个共价连接完整、总电荷为零的 39 原子 ZIL 分子，不会把三个片段分别放入水中模拟，也不会把片段水化数相加作为完整分子的水化数。

## 2. 修改原因

原全分子计算已经完成 5 个构象、15 个取向的气相 HF/6-31G* ESP 和两阶段 RESP，但拟合结果出现：

- 最小原子电荷：`-4.1386 e`；
- 最大原子电荷：`+6.6531 e`；
- 39 个原子中 14 个超过 `|2.0 e|`；
- 电荷拟合矩阵条件数约为 `1.6 × 10^6`。

独立 Psi4 对照证明 ESP 数值和单位正确。提高网格密度、改变对称约束、增强 RESP 约束、使用单构象以及增加局部电荷组约束均未得到可接受电荷。因此，失败结果被解释为柔性两性离子全分子点电荷拟合病态，而不是量子化学任务或软件执行失败。

原有完整分子的 QM 数据不删除。它们将作为独立参照，用于检验片段组装电荷能否重现完整分子的静电势和偶极矩。

## 3. 总体策略

```text
文献与参数来源核对
  -> 定义带封端原子的化学片段和原子映射
  -> 每个片段生成并筛选多构象
  -> 片段 HF/6-31G* 几何优化和 ESP
  -> 各片段两阶段 RESP
  -> 删除封端原子并处理连接原子电荷
  -> 组装完整分子候选电荷
  -> 使用原完整分子 QM 数据反向验证
  -> GAFF2 拓扑和缺失参数审核
  -> Amber/OpenMM/GROMACS 交叉验证
  -> 完整分子水盒内部短程测试
  -> 生成验证报告并停止
  -> 用户明确批准后才开放正式生产计算
```

## 4. 片段设计

### 4.1 化学区域

第一版将完整分子划分为三个电荷区域：

| 区域 | 目标形式电荷 | 需要保留的化学环境 |
|---|---:|---|
| 咪唑鎓核心及 N–CH2 连接区 | `+1 e` | 两个环氮、咪唑鎓环以及两个 N–C 连接环境 |
| 丙基磺酸盐区域 | `-1 e` | 三个磺酸根氧、硫原子和丙基链 |
| 二甘醚侧链 | `0 e` | 两个醚氧、末端甲氧基和与咪唑鎓相连的碳链 |

这里的 `+1/-1/0` 是区域电荷目标，不代表最终需要把分子拓扑拆成三个残基。

### 4.2 封端模型

在运行量化计算前，脚本必须生成并保存以下内容供人工检查：

- 每个片段的带原子映射 SMILES；
- 封端原子的编号和删除规则；
- 片段原子到完整分子 39 个原子的映射表；
- 每个连接键两侧允许接受电荷修正的原子；
- 删除封端原子前后的目标总电荷。

计划比较两种封端方案：

- 候选 A：甲基封端；
- 候选 B：乙基封端。

封端原子只用于保持片段价态和局部化学环境，不进入最终拓扑。两种候选用于评估电荷对封端选择的敏感性，不能仅选择数值看起来更好的一套而不报告差异。

## 5. 片段构象与 RESP 设置

每个片段采用以下初始设置：

- 初始构象尝试数：`100–300`；
- 代表构象数：`5–8`；
- 构象去重：重原子 RMSD；
- 初筛能量：MMFF94；
- QM 几何优化：气相 `HF/6-31G*`，`gau_tight`；
- ESP：与优化相同的 `HF/6-31G*`；
- 每个构象取向数：3；
- RESP：标准两阶段拟合；
- 对称原子：施加等价约束；
- 片段总电荷：分别固定为 `+1`、`-1` 和 `0`；
- 随机种子、软件版本、输入哈希和 QM 输出哈希全部记录。

PsiRESP、Psi4 和 AmberTools 负责现有标准算法。项目脚本只负责任务编排、原子映射、输入验证、状态记录和结果审核，不重新实现 RESP 求解器。

## 6. 连接原子与电荷组装

### 6.1 基本原则

删除封端原子后产生的电荷差只能分配到对应连接键附近预先指定的一个或两个原子，不能平均摊到整个分子，也不能为了使总电荷恰好为零而任意修改远端官能团。

组装后必须满足：

```text
完整分子原子数 = 39
完整分子总电荷 = 0 ± 1e-4 e
咪唑鎓区域电荷约为 +1 e
磺酸盐区域电荷约为 -1 e
醚链区域整体接近 0 e
```

### 6.2 两套候选的处理

甲基封端和乙基封端分别产生一套完整分子候选电荷。两套候选都必须经过相同的完整分子验证，比较：

- 每个原子的电荷差；
- 官能团区域总电荷差；
- 完整分子 ESP 误差；
- 偶极矩误差；
- 三个代表构象的分子力学能量和构象行为。

如果连接区或关键亲水原子的电荷对封端方案高度敏感，则片段模型不具备足够可转移性，参数化在此处停止，不进入 MD。

## 7. 完整分子反向验证

片段组装电荷不重新拟合到原全分子数据，而是直接用于预测原来 5 个完整分子构象的 QM 静电性质。这样可以检验片段电荷的可转移性，避免再次落入全分子病态拟合。

### 7.1 硬性拦截

- 总电荷误差小于 `1e-4 e`；
- 所有电荷为有限数；
- 任一原子电荷绝对值大于 `2.0 e` 时自动拒绝；
- 不允许出现相邻原子之间异常的大幅正负交替；
- 39 个原子的顺序和元素必须与完整分子映射完全一致。

`|q| <= 2.0 e` 只是保守异常值筛查，不代表参数自动通过。

### 7.2 定量比较

对每个完整分子构象记录：

- QM ESP 与候选点电荷 ESP 的 RMSE；
- 相对 ESP 误差；
- QM 与候选模型偶极矩的大小、方向和夹角；
- 各化学区域对静电势误差的贡献；
- 甲基/乙基封端候选之间的差异。

最终报告同时保留原全分子 RESP 的极端电荷结果作为失败基线，不能只展示新的候选结果。

## 8. GAFF2 拓扑生成与审核

候选电荷通过完整分子静电验证后，按以下标准工具链生成拓扑：

```text
Antechamber -> GAFF2 原子类型
Parmchk2    -> 缺失参数候选
tleap       -> Amber prmtop/inpcrd
ParmEd      -> GROMACS itp/top/gro
```

此前 `parmchk2` 已经产生 5 项 `Using the default value` improper 参数。新路线必须逐项记录其原子类型、对应结构、参数来源和采用理由。不能把 `parmchk2` 成功退出当作参数已经可靠。

如果 GAFF2 中不存在可信的直接或等价参数，则对相关扭转/面外项单独制定 QM 扫描方案；在完成拟合与验证前不得使用占位参数运行目标体系。

## 9. Amber/OpenMM/GROMACS 交叉验证

正式候选拓扑必须检查：

- 原子数量、元素、名称和顺序；
- 总电荷及逐原子电荷；
- 键、角、二面角和 improper 数量；
- Lennard-Jones 参数；
- 1–4 静电和 Lennard-Jones 缩放；
- Amber/OpenMM 与 GROMACS 单点能量分项；
- Amber/OpenMM 与 GROMACS 原子受力；
- 三个代表构象的 `gmx grompp -maxwarn 0`；
- 三个代表构象的能量最小化。

所有比较必须保存输入哈希、软件版本、数值容差和完整报告。

## 10. 内部短程贯通测试

参数和拓扑通过静态审核后，只运行实施阶段内部测试：

```text
体系：1 个完整 ZIL + 4.5 nm 立方 TIP3P 水盒
水数：预计约 3000 个，以实际溶剂化结果为准
盐/反离子：不添加
温度：298.15 K
压力：1 bar
流程：EM -> 100 ps NVT -> 500 ps NPT -> 0.5 ns MD
```

检查项目：

- 无 NaN、LINCS 错误或异常大力；
- 温度、压力、势能和密度稳定；
- 水盒密度与所用 TIP3P 模型相符；
- 分子没有因异常静电作用立即塌缩；
- 咪唑鎓—磺酸根距离和构象变化连续；
- 磺酸根、醚氧和咪唑鎓区域的 RDF 可正常计算；
- GROMACS 与 MDAnalysis 的逐帧去重水化数一致。

0.5 ns 结果只证明代码、拓扑和分析链路能够运行，不能作为正式结合水数量或发表结果。

## 11. 实施文件结构

确认实施后新增以下内部参数化文件：

```text
parameterization/
├─ fragment_config.json
├─ scripts/
│  ├─ build_fragments.py
│  ├─ run_fragment_resp.py
│  ├─ assemble_fragment_charges.py
│  └─ validate_assembled_charges.py
└─ results/
   ├─ fragments/
   └─ assembled_candidate/
```

大型 QM 临时文件写入显式指定的外部运行目录，不写入项目源码目录。项目目录只保存配置、脚本、小型参数文件、哈希清单和验证报告。

最终交付仍只保留一个正式生产入口：

```bash
python3 scripts/run_production.py --run-root /data/zwitterion_hydration_runs
```

片段构象生成、RESP、拓扑审核和短程测试属于实施阶段内部工具，不作为交付时的第二种运行模式。

## 12. 阶段门槛与停止条件

### 阶段 A：片段定义

输出原子映射和封端规则，人工检查后才能启动 QM。

### 阶段 B：片段 RESP

任一片段出现极端电荷、净电荷错误或明显病态拟合时停止。

### 阶段 C：完整分子验证

两种封端方案差异过大，或完整分子 ESP/偶极矩无法合理重现时停止。

### 阶段 D：拓扑验证

存在未经审核的缺失参数、跨引擎能量/力不一致或 `grompp` 警告时停止。

### 阶段 E：内部短测

短轨迹出现数值不稳定或明显非物理行为时停止并回到参数审核。

### 阶段 F：实施交付

生成参数化与短测报告后停止，不自动启动三条 100 ns 正式轨迹。只有用户审阅报告并明确批准正式生产后，才创建生产验收标记并运行正式入口。

## 13. 预计资源与时间

本地 CPU 足够完成参数化与内部短测，暂不需要超算：

| 工作 | 预计时间 |
|---|---:|
| 片段和原子映射生成与检查 | 0.5–1 小时 |
| 三个片段、两种封端候选的 QM/RESP | 2–8 小时 |
| 完整分子 ESP/偶极矩验证 | 0.5–2 小时 |
| GAFF2 参数审核与跨引擎验证 | 1–3 小时；若需要扭转扫描则另计 |
| 0.5 ns 内部短程测试 | 约 20–60 分钟 |

耗时以实际构象数量、Psi4 收敛情况和缺失参数审核结果为准。任何阶段失败都优先报告证据和原因，不通过放宽标准强行进入下一阶段。

## 15. 实施记录（2026-08-30）

阶段 A 已完成：两种封端方案的六个模型均通过价态检查，且每种方案都无重复覆盖完整分子的 39 个原子。六个 PsiRESP 任务的原子顺序、封端组索引和约束数量也已在不运行 QM 的条件下验证。

第一个真实任务 `methyl/sulfonate` 完成 3 个优化构象、9 个 ESP 取向和两阶段 RESP 后被拒绝。标准设置得到最大原子电荷 `+2.3725 e`；去掉封端零电荷约束后最大值仍为 `+2.3772 e`，说明问题不是封端总电荷约束，而是带电磺酸盐模型的原子级 ESP 分解仍然病态。

进一步诊断表明，增加中性烷基电荷组并对氢施加更强 restraint 可以把电荷压回较小范围，但这会偏离原先标准 RESP 协议，且结果依赖人为 restraint 强度。因此其余五个片段 QM 暂停，不能用数值变小作为自动接受依据。

Nguyen 和 Shao 2020 年论文的官方 SI Table S1 已读取并记录。其 Z2C/Z3C 是与目标咪唑鎓—丙基磺酸盐部分高度相关的公开参数参考，full-charge 表中给出 `S = +1.32 e`、三个等价磺酸根氧各 `-0.76 e`，以及咪唑鎓和碳链的完整分组电荷。源数据保存在 `parameterization/references/jced_2020_z2c_z3c_table_s1.json`，当前未映射、未接受，也未写入拓扑。

下一步建议改为“文献锚定的约束 RESP”：只把经过明确标签映射的相同咪唑鎓—丙基磺酸盐核心作为固定或窄约束参考，使用完整分子 QM ESP 对目标特有的二甘醚侧链及连接区进行 RESP；GAFF2 仍提供完整分子的键合和 Lennard-Jones 参数。采用该混合电荷路线前需要用户确认，并必须重新验证完整分子 ESP、偶极矩和封端/约束敏感性。
