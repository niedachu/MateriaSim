# 非共价离子对紧密结合水：实施方案与风险排查

## 1. 目标

计算一个非共价离子液体离子对在纯水中的紧密结合水数，并与已完成的共价两性离子 ZIL 结果比较。

- 阳离子：`CC[N+]1=CN(CCOCCOC)C=C1`，净电荷 `+1`；
- 阴离子：`CS(=O)([O-])=O`（甲基磺酸根），净电荷 `-1`；
- 体系：1 个阳离子 + 1 个阴离子，总净电荷 0；
- 参照体系：已完成的共价 ZIL（4.5 nm、2957 TIP3P 水、10 ns）结果，正式值为 `17.42 ± 0.07` 个紧密结合水/ZIL。

离子之间不建立任何跨分子的键、角、二面角或人为约束；它们只通过 GAFF2 非键相互作用、PME 静电和水介导作用相互影响。

## 2. 可比性冻结

为使比较只尽可能反映“共价两性离子”与“可自由缔合的离子对”的差异，新体系固定采用：

| 项目 | 离子对协议 |
|---|---|
| 力场与电荷 | GAFF2 + AM1-BCC（AmberTools 24.8） |
| 水模型 | AMBER TIP3P |
| 盒子 | 4.5 nm 立方盒 |
| 水数 | 目标为2957个TIP3P水；正式开始前必须实际核验 |
| 温度、压力 | 298 K、1 bar |
| 平衡 | EM → 1 ns NVT → 5 ns NPT |
| 正式生产 | 1 条连续10 ns轨迹，2 fs，轨迹每2 ps输出 |
| 长程静电 | PME，1.2 nm实空间截断 |
| 统计窗口 | 5--10 ns，共2501帧 |
| 误差 | 五个连续1 ns时间块的均值与SEM |

这与ZIL正式计算匹配。单重复10 ns只能给出时间块不确定度，不能量化独立构象、速度种子或力场不确定度。

## 3. 已识别风险与处理方案

| 风险 | 为什么重要 | 排查/缓解措施 | 生产放行标准 |
|---|---|---|---|
| 离子电荷错误或原子顺序错位 | 分别参数化的 `+1/-1` 离子很容易在转换后电荷或atom mapping出错 | 分别核验MOL2、Amber拓扑、GROMACS ITP的原子数、原子顺序和总电荷；体系总电荷必须为0 | 阳离子=`+1`、阴离子=`-1`、体系=`0`，无占位参数 |
| 阴阳离子被误连成共价分子 | 会把离子对问题错误变成另一种两性离子问题 | `CAT.itp`、`ANI.itp`独立 `[ moleculetype ]`；拓扑中只写各一个分子 | 跨离子键、角、二面角和约束均为0 |
| AM1-BCC 对离子参数不稳 | 高电荷密度SO3−与咪唑鎓的电荷决定水化强度 | 使用离子各自的形式电荷进行 AM1-BCC；检查生成日志、总电荷、最小化几何；用OpenMM/GROMACS单点能量与力交叉核对 | 两套引擎能量/力误差与现有ZIL接受阈值同等级 |
| 2957水的精确构建 | 与ZIL不同体积的溶质会使普通溶剂化命令留下不同水数 | 从4.5 nm水盒构建并在去重叠后调整至恰好2957个水；将实际水数写入运行清单 | `SOL = 2957`，盒边长4.5 nm，初始无原子重叠 |
| 人为初始接触离子对 | 若初始相距很近，短轨迹可能只反映初始构型 | 初始阳、阴离子中心距离设为约1.5--2.0 nm，彼此不重叠；NVT/NPT后检查距离演化 | EM、NVT、NPT稳定且无原子重叠/LINCS问题 |
| 离子配对改变水数 | 自由离子、溶剂分离离子对和接触离子对的水化可能不同 | 生产中记录阳/阴离子质心距离分布；辅助报告接触与溶剂分离帧占比 | 主结论注明离子对状态分布，不把单一平均数误解为永久分离离子 |
| RDF截断直接照搬ZIL | 阴离子/阳离子局部环境与共价ZIL不完全相同 | 用新体系5--10 ns轨迹重新求各位点RDF第一稳定极小值 | 三个位点截断均来自正式RDF而非smoke轨迹 |
| 多位点水重复计数 | 同一水可同时接触阳、阴离子或多个位点 | 每帧按水氧ID取并集；分别保存各位点数和总去重数 | 总数不高于位点数之和 |
| GROMACS动态选择优先级 | 未分配外层筛选的 `or` 表达式会把非水氧误纳入 | 在每一个 `or` 分支内重复 `resname SOL and name OW` 约束 | GROMACS 与 MDAnalysis 的2501帧逐帧计数完全一致 |
| 10 ns采样不足 | 离子配对/解离与水化交换可能慢于现有ZIL | 比较0--5与5--10 ns均值，报告五个时间块；若明显漂移则不宣布收敛 | 无明显时间漂移；否则建议延长或加独立重复 |
| 物理解释过度 | 新阴离子是甲基磺酸根，而ZIL的磺酸根经丙基连接，结构不只差“是否共价连接” | 报告为这两个具体化学体系的比较；不泛化为所有离子液体规律 | 最终报告明确该结构差异与单轨迹限制 |

## 4. 实施步骤

### 阶段 A：独立离子参数化与静态验收

1. 用 AmberTools 对阳离子以 `+1`、阴离子以 `-1` 分别运行 GAFF2 + AM1-BCC；
2. 生成独立 `CAT.itp`、`ANI.itp` 和对应坐标；
3. 检查每个离子的净电荷、原子名、原子顺序、键合及缺失参数；
4. 在代表构象上做最小化，检查咪唑鎓环、磺酸根和醚链几何；
5. 在真空单点上比较 Amber/OpenMM 与 GROMACS 势能和力。

本阶段只验证参数化，不启动正式水化生产。

### 阶段 B：体系构建与短程贯通测试

1. 在4.5 nm盒中放置一对离子，初始中心距离约1.5--2.0 nm；
2. 用TIP3P水填充并将水数精确调整为2957；
3. 编写 `system.top`：`CAT 1`、`ANI 1`、`SOL 2957`；
4. 以ZIL同一套EM/NVT/NPT/生产设置运行短程贯通测试；
5. 检查能量最小化、温度、密度、压力、约束误差、NaN与LINCS；
6. 用短轨迹仅验证分析脚本能够识别阳离子位点、阴离子位点、水氧及离子间距离；短轨迹数值不作为正式水化数。

此处生成验收报告并暂停；不自动启动正式10 ns生产。

### 阶段 C：冻结正式输入

通过阶段A/B后，冻结：

- `CAT.itp`、`ANI.itp`、`system.top`与离子起始坐标；
- 4.5 nm/2957水的运行清单；
- EM、NVT、NPT和生产MDP；
- 单重复、速度种子、10 ns时长和检查点频率；
- 所有正式文件的SHA-256及接受记录。

只有在用户明确确认后启动正式生产。

### 阶段 D：正式生产

按冻结入口连续执行EM、1 ns NVT、5 ns NPT与10 ns生产。每10分钟写检查点；若进程中断，保持输入不变，从 `prod.cpt` 用 `-cpi ... -append` 续跑。

计算规模与已完成ZIL体系近似相同。Windows CPU实际耗时取决于电脑是否被其他任务占用；按已完成ZIL生产的实际经验，应预留约一天量级，而不是只依据理想基准速度估计。

## 5. 正式分析

### 5.1 位点定义

正式分析最少包含：

- 阴离子磺酸根：三个 `SO3−` 氧；
- 阳离子醚氧：两个醚氧；
- 阳离子咪唑鎓C--H：三个环C--H；
- 阳离子/阴离子质心距离。

最终原子名由正式拓扑决定，不能依据当前SMILES手工猜测后直接生产。

### 5.2 水数

1. 从5--10 ns计算各位点到水氧的RDF和累计配位数；
2. 从每条RDF的第一壳层峰后第一稳定极小值获取正式截断；
3. 逐帧选择水氧，并对全部位点命中的水氧ID取并集；
4. 输出总水数、各位点水数、重叠、分布、5个时间块均值及SEM；
5. 用相同截断值另算0--5 ns，用于检查明显时间漂移；
6. 使用GROMACS `gmx select`与MDAnalysis逐帧独立验证；正式接受标准为 `mismatch_count = 0`。

### 5.3 与ZIL比较

主要比较量为：

\[
\Delta N_\mathrm{tight}=N_\mathrm{tight}^{\mathrm{ion\ pair}}-17.419
\]

同时报告各体系的时间块SEM、RDF截断、离子对质心距离分布和分析窗口。不得把差异简单归因于“静电作用更强/更弱”：它也可能来自阴离子甲基取代、离子间距离和离子配对状态。

作为敏感性检查，对同类位点可再用与ZIL相同的统一截断重算一次；主结果始终使用各体系由自身正式RDF得到的截断。

## 6. 预期交付物

- 参数化验收报告和交叉引擎单点核对；
- 体系构建清单（盒长、离子数、水数、净电荷）；
- smoke报告与正式冻结记录；
- 完整生产轨迹、检查点与日志；
- RDF、累计配位数、离子间距离分布；
- 逐帧去重水数CSV/JSON、时间块不确定度、GROMACS/MDAnalysis核对；
- 一份离子对与ZIL并列比较报告，以及10 ns盒子快照。

## 7. 当前决策点

方案本身没有需要在开工前改变研究目标的技术阻碍。实际是否达到2957水、AM1-BCC离子电荷与跨引擎能量/力一致性，必须在阶段A/B通过实际检查后再决定是否冻结。

用户确认本方案后，下一步只执行阶段A和阶段B（参数化、体系构建、dry-run/smoke和验收），并在正式10 ns生产前再次暂停等待明确授权。
