# 拓扑文件要求

将经审查的参数化文件放在本目录。`system.top.template` 只是结构示例，含有占位符，不能直接参与 `grompp`。

必须核对：

1. `zil.itp` 中原子顺序与 `zil.gro` 完全一致。
2. 分子电荷总和为 0；不可把内盐误作中性、无局域电荷的普通分子。
3. 水模型、组合规则、1-4 缩放和非键合参数与离子液体参数化路线相容。
4. 磺酸根氧、两个咪唑氮及醚氧的原子名和原子类型已被记录，以便生成位点 RDF。
5. `system.top` 的 `[ molecules ]` 初始只含一分子 `ZIL`，不要预写 `SOL 0`；`gmx solvate -p` 会追加唯一的 `SOL` 条目和实际水分子数。

不要将预测的水化数写入任何实验测量字段。
