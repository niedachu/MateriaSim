# 单分子两性离子水化数模拟项目设计

## 1. 项目目标

本项目使用 GROMACS 对一个两性离子分子在过量纯水中的水化行为进行经典全原子分子动力学模拟，并计算其结合水数量。

- 化合物：`3-(1-(2-(2-methoxyethoxy)ethyl)-1H-imidazol-3-ium-3-yl)propane-1-sulfonate`
- SMILES：`O=S(CCC[N+]1=CN(CCOCCOC)C=C1)([O-])=O`
- 溶质数量：1 个分子
- 溶剂：纯水，不加盐和反离子
- 温度：298 K
- 压力：1 bar
- 力场路线：GAFF2 + AM1-BCC 电荷
- 模拟引擎：GROMACS
- 主要结果：第一水化层中去重后的水分子数及其统计不确定度

该分子的咪唑鎓部分形式电荷为 `+1`，磺酸根部分形式电荷为 `-1`，整个分子的形式净电荷必须为 `0`。参数化和格式转换后都必须再次验证这一点。

## 2. 科学问题和结果边界

### 2.1 主要科学问题

在 298 K、1 bar 的纯水环境中，一个目标两性离子分子的第一水化层平均包含多少个水分子？

### 2.2 “结合水”的主要定义

主要结果定义为：在每一帧轨迹中，水分子氧原子进入目标分子亲水位点各自第一水化层的水分子集合；对同一帧内被多个位点同时捕获的水分子按水残基编号去重，然后对时间和独立重复轨迹求统计量。

第一水化层边界不预先指定固定距离，而是从对应径向分布函数 RDF 第一峰之后的第一个稳定极小值确定。需要分别确定：

- 磺酸根氧位点的截断距离；
- 两个醚氧位点的截断距离；
- 咪唑鎓环阳离子区域的截断距离；
- 整个分子表面的 proximal hydration 截断距离，作为补充指标。

### 2.3 辅助结果

- 各亲水位点的配位数；
- 水化数逐帧分布；
- 溶质-水氢键数量；
- 第一水化层水的连续和间歇驻留时间；
- 分子内部正负电荷基团距离及其与水化数的相关性；
- 三条独立轨迹之间以及轨迹前后半段之间的收敛性。

水化数是统计平均值和概率分布，不应表述为固定化学计量整数，也不应冒充实验测量值。

## 3. 软件与硬件现状

当前 macOS 本地验收环境已经确认：

- Homebrew GROMACS 2026.3；
- mixed precision；
- thread-MPI 和 OpenMP；
- ARM NEON SIMD；
- 当前构建未启用 GPU；
- GROMACS 由 `PATH` 中的 `gmx` 命令解析，也可用 `--gmx` 显式指定原生可执行文件。

macOS 分析环境位于 `.venv-macos-analysis`；Linux 必须单独创建环境，不能跨系统复制虚拟环境。
GAFF2 + AM1-BCC 暂存拓扑和 0.5 ns 内部 smoke 已经完成，正式拓扑与验收标记已经冻结。

当前 macOS GROMACS 构建使用 CPU。若以后在 Linux GPU 节点运行，必须先用同一测试体系比较 CPU 和 GPU 的 `ns/day`，并以 `gmx --version` 和运行日志确认后端；不能只根据显卡存在就假定 GROMACS 已使用 GPU。

## 4. 总体数据流

```text
SMILES
  -> 三维构象生成与构象筛选
  -> 全分子 AM1-BCC 电荷
  -> GAFF2 原子类型与缺失参数生成
  -> Amber 拓扑验证
  -> GROMACS 拓扑转换与交叉验证
  -> 4.5 nm 纯水盒
  -> 能量最小化
  -> NVT 平衡
  -> NPT 平衡
  -> 1 ns CPU/GPU 基准测试
  -> 3 x 100 ns 独立生产轨迹
  -> RDF 和第一极小值
  -> 去重结合水计数与驻留时间
  -> 收敛性、误差和最终报告
```

## 6. 参数化设计

### 6.1 构象采样

目标分子含柔性醚链和丙基磺酸根链。构象集合用于选择参数化输入几何，并为三条独立MD提供伸展、中间和折叠起始状态；AM1-BCC不进行本项目此前尝试的多构象RESP共同拟合。

计划：

- 初始生成不少于 50 个构象；
- 根据几何相似度聚类；
- 选择约 5 至 10 个代表性构象；
- 记录构象选择准则、相对能量和随机种子。

### 6.2 AM1-BCC电荷

采用AmberTools `antechamber -c bcc -at gaff2 -nc 0 -eq 1`生成全分子AM1-BCC电荷并等价化化学等价原子。只允许修正由MOL2文本精度造成、绝对值不超过`0.01 e`的总电荷残差；修正对全部原子均匀施加，并保留修正前后数值。

正式接受电荷前必须检查：

- 总电荷绝对偏差小于 `1e-4 e`；
- 化学等价原子电荷一致；
- 磺酸根、咪唑鎓和醚氧电荷方向符合化学结构；
- 不存在异常大、明显由错误质子化或错误构象产生的原子电荷；
- 所有量化输入、输出和拟合文件完整保存。

### 6.3 GAFF2参数

AM1-BCC产生原子电荷，键合与Lennard-Jones参数由GAFF2路线产生：

- `antechamber` 分配 GAFF2 原子类型；
- `parmchk2` 生成缺失参数文件；
- 审查所有低置信度或类比得到的二面角参数；
- `tleap` 生成 Amber `prmtop/inpcrd`；
- 使用 ParmEd 或验证过的转换工具生成 GROMACS 文件。

转换后比较 Amber 与 GROMACS 的：

- 原子数量和原子顺序；
- 总电荷；
- 键、角、二面角数量；
- 1-4 静电和Lennard-Jones缩放；
- 非键合组合规则；
- 单点势能分项。

只有交叉验证通过，`zil.itp`、`zil.gro` 和 `system.top` 才可标记为正式输入。

## 7. 分子动力学体系设计

### 7.1 水模型与水盒

主路线使用与GAFF2兼容的AMBER TIP3P水模型。主体系采用4.5 nm立方盒，预计包含约3,000个水分子。溶质只有一个分子，体系不加入盐或反离子。

正式结果需要记录实际水分子数量、盒尺寸和初始密度。为检查有限尺寸效应，主模拟完成后可选做一个更大水盒的短程敏感性测试；该测试结果不得与主轨迹静默合并。

### 7.2 通用非键合设置

- 三维周期性边界；
- Verlet cutoff scheme；
- PME长程静电；
- `rcoulomb = 1.2 nm`；
- `rvdw = 1.2 nm`；
- `DispCorr = EnerPres`；
- 邻居表更新设置在所有阶段保持一致；
- 2 fs时间步长阶段使用 `constraints = h-bonds` 和 LINCS。

### 7.3 模拟阶段

#### 阶段A：能量最小化

- steepest descent；
- 最多50,000步；
- 目标最大力不高于 `500 kJ mol-1 nm-1`；
- 检查是否存在原子重叠、LINCS警告或异常高势能。

#### 阶段B：NVT平衡

- 长度1 ns；
- 温度298 K；
- V-rescale恒温；
- 初速度由随机种子生成；
- 检查温度、势能和分子构象是否稳定。

#### 阶段C：NPT平衡

- 长度5 ns；
- 298 K、1 bar；
- C-rescale恒压；
- 检查密度、盒尺寸、压力和势能；
- 最后2 ns的密度和盒尺寸不得存在持续漂移。

#### 阶段D：性能和稳定性测试

- 从同一NPT检查点分别运行1 ns CPU和GPU测试；
- 使用不同输出目录，禁止覆盖；
- 比较 `ns/day`、能量一致性、温度、密度和日志警告；
- 只有GPU测试正确且确实更快，才用于生产模拟。

在实施期间，使用与正式体系一致的4.5 nm水盒执行一次内部短程贯通测试：能量最小化、100 ps NVT、200 ps NPT和200 ps测试轨迹。此测试只验证软件、拓扑、约束、输出和分析链路，不用于确定正式RDF截断值或报告水化数。测试全部由实施者在交付前完成，不作为最终用户可选运行模式。

#### 阶段E：生产模拟

- 3条相互独立的轨迹；
- 每条100 ns；
- 分别从伸展、中间和折叠的代表构象开始，各自独立执行EM、NVT和NPT；
- 使用不同初速度随机种子；
- V-rescale恒温；
- Parrinello-Rahman恒压；
- 每10 ns保留检查点并支持断点续算；
- 坐标输出默认每2 ps一次，以支持水交换和驻留时间分析；
- 能量和日志输出频率需兼顾诊断与磁盘占用。

三条独立轨迹比单纯把一条轨迹延长到300 ns更适合评估初始条件和构象采样的不确定度。

## 8. 分析设计

### 8.1 轨迹预处理

- 使用周期性边界条件还原完整溶质分子；
- 将溶质置于盒中心；
- 保留用于距离计算的原始盒矢量；
- 分析脚本必须显式使用最小镜像距离；
- 检查每条轨迹的帧数、时间间隔和缺失帧。

### 8.2 RDF与截断距离

分别计算站点RDF，并在平滑和稳定性检查后寻找第一峰后的第一个极小值。自动检测值必须配合图形人工审核，截断值及选取依据写入结果元数据。

不能把磺酸根、醚氧和咪唑鎓位点使用同一个未经验证的统一截断值。

### 8.3 去重水化数

对每一帧：

1. 按各位点自己的截断值确定邻近水氧；
2. 将所有位点匹配到的水残基编号合并；
3. 对水残基编号去重；
4. 记录该帧总结合水数和各位点局部计数；
5. 保存逐帧CSV，不只保存最终平均值。

### 8.4 统计和收敛

每条轨迹分别报告：

- 平均值、标准差、中位数；
- 5%、25%、75%和95%分位数；
- 按时间区块计算的均值；
- 前50 ns与后50 ns差异；
- 自相关时间和有效独立样本数。

跨三条轨迹报告重复间均值、标准差和95%置信区间。若三条轨迹之间差异显著，则延长模拟，而不是只选择最接近期望的一条轨迹。

### 8.5 现成工具复用与双路线验证

- 构象生成优先调用RDKit，需要更强柔性构象搜索时调用CREST/xTB；
- AM1-BCC、GAFF2和Amber拓扑调用AmberTools的 `antechamber`、`parmchk2` 和 `tleap`；
- Amber/GROMACS拓扑转换和解析调用ParmEd，不自行实现格式转换；
- 水盒、输入预处理、MD、RDF、氢键和动态选择优先调用GROMACS原生工具；
- 驻留概率和独立轨迹解析调用MDAnalysis/waterdynamics；
- 自写代码仅负责配置、位点映射、分子编号去重、统计、交叉验证和结果汇总。

总水化数必须用两条独立分析路线验证：一条由 `gmx select -os/-oi` 输出每帧的水氧数量和编号，另一条由MDAnalysis读取同一轨迹独立计算。在人工构造的已知答案轨迹和内部短程轨迹上，两者的逐帧去重计数必须一致。

## 9. 质量控制门槛

### 门槛1：参数化通过

- 总电荷为0；
- 无缺失参数；
- GROMACS `grompp -maxwarn 0`通过；
- Amber/GROMACS拓扑和单点能量检查通过；
- 原子命名和分析位点映射已经记录。

### 门槛2：平衡通过

- 无LINCS、非有限能量或粒子飞出警告；
- 温度稳定在目标值附近；
- 密度与盒尺寸无持续漂移；
- 分子保持化学结构完整；
- 内部离子对构象并非由错误跨周期边界造成。

### 门槛3：生产和分析通过

- 三条轨迹均完整或能从检查点连续恢复；
- RDF第一极小值在分块分析中稳定；
- 水化数时间序列无持续漂移；
- 重复间结果在统计不确定度范围内可解释；
- 最终报告明确区分模型结果、统计不确定度和方法局限。

## 10. 自动化与安全原则

- `dry-run` 和短程 `smoke` 仅是实施期间的内部验证步骤，由实施者在交付前完成，不作为最终交付模式；
- 内部短程贯通测试完成后生成验收报告并暂停，确认参数、拓扑、输出和分析链路通过后，再冻结正式输入；
- 最终交付只保留 `scripts/run_production.py` 一个正式生产入口，不提供运行模式切换参数；
- 正式生产入口在启动前依然执行强制前置检查；任一检查失败即终止，但不将这些检查暴露为另一种用户可选模式；
- 不允许使用占位拓扑启动GROMACS；
- 不允许使用 `-maxwarn` 跳过未知警告；正式设置保持 `-maxwarn 0`；
- 每个阶段使用独立输出目录；
- 正式轨迹不得被测试运行覆盖；
- 保存命令行、软件版本、随机种子、输入文件校验值和运行时间；
- 分析结果必须能从保存的轨迹和配置重新生成；
- 原始量化输出、正式拓扑和生产轨迹视为只读科学记录。

## 11. 计算资源与预计时间

单个4.5 nm水盒预计约9,000个原子，本地内存和RTX 2060显存足够。项目不需要多节点超算。

预计耗时范围：

- 环境安装：取决于下载和WSL状态；
- 多构象量化与RESP：数小时至一天；
- 建模和平衡：数小时以内；
- 1 ns基准测试：用于获得本机真实 `ns/day`；
- 3 x 100 ns生产模拟：由基准结果推算，可能需要数天。

生产时间不能仅根据显卡型号估计。必须用正式体系的1 ns基准日志计算：

```text
预计天数 = 目标模拟长度(ns) / 实测性能(ns/day)
```

## 12. 主要风险和处理

### 参数化风险

AM1-BCC是固定电荷近似，内盐环境和构象极化不能被显式响应。保留多种起始构象，并在报告中说明该限制；5项默认improper必须通过几何稳定性及QM或文献依据审核。

### 水模型风险

TIP3P对水动力学和驻留时间存在模型局限。主结果以TIP3P为准，并在报告中明确；如需更高可信度，再增加其他AMBER兼容水模型的敏感性计算，不能把不同模型结果直接合并。

### 有限尺寸风险

目标分子净电荷为0但偶极矩可能较大。通过4.5 nm主水盒和更大盒短程测试判断水化数是否受盒尺寸影响。

### GPU风险

当前OpenCL构建不保证RTX 2060得到最佳性能。首先做CPU/GPU等条件基准；需要时再转CUDA构建，不能为了速度改变物理参数。

### 统计风险

第一水化层水交换和分子折叠可能具有长相关时间。使用三条独立轨迹、分块统计和有效样本数避免把大量相关帧误认为大量独立样本。
